# LoL Rivals

**League of Legends tools for comparing players, champion win rates, and team compositions using Riot Games match data.**

🌐 **Live Website:** https://lolrivals.com/

## Overview

LoL Rivals is a League of Legends statistics website built around tools that are not commonly presented clearly or directly on existing League statistics websites.

The project focuses on answering specific questions about players, matches, champions, and team compositions through a simple interface.

The goal was not to recreate another general League statistics website, but to build focused tools around specific questions that players may want answered but often have difficulty finding in one place.

## Features

### Player Match History Comparison

Compare two League of Legends players and identify their shared matches.

This makes it easier to see how two players have performed against each other or alongside each other across their recent games.

### Champion Win Rate Analysis

Check how a player performs with or against a specific champion.

This provides a more focused view of player performance than a general overall win rate.

### Team Composition Analysis

Compare the performance of different team compositions, including comparisons between lethality-oriented and bruiser-oriented teams.

The feature is designed to answer questions about how specific team setups perform rather than only looking at individual champion statistics.

## Data Source

The project uses the **Riot Games API** to retrieve League of Legends match and player data.

The application processes the available match information and presents it through the website's custom tools.

## Development Approach

This project was developed iteratively with the assistance of **Claude**, an AI development tool.

The development process involved describing the desired functionality in natural language, implementing the feature, testing it, identifying issues or changes, and iterating until the result matched the intended behavior.

This approach was particularly useful for experimenting with new ideas and rapidly turning concepts into working features.

## Challenges & Problem Solving

One of the main challenges was turning relatively specific statistical ideas into reliable tools using the data available through the Riot Games API.

Rather than building a generic statistics site, the project required determining how the available match data could be processed to answer more specific questions.

The application was developed through repeated testing and refinement to improve the accuracy and usability of the results.

## Project Goals

The main goals of LoL Rivals were:

* Build League of Legends tools that answer specific questions.
* Present statistics in a way that is easy to understand.
* Experiment with Riot Games API data.
* Create useful features that are not commonly presented together on other League websites.
* Learn through building and iterating on a real-world web application.
